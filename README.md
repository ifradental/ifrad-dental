# ifrad-dental

Dentist PRO 7.0 - Advanced Dental EMR & Clinical Management Software (Next.js + Electron + IndexedDB).

## Features
- Smart Prescription Generator (Rx, CC, OE, DX, Investigation, Advice)
- 20,000+ Brand & Generic Drug Database with Instant Autocomplete
- Intelligent Dosage Auto-fill & Template Memory
- A4 Prescription Printing (Full Digital Letterhead & Pre-printed Doctor Pad Modes)
- Clinic Logo & Prescription Sheet Watermark Customization
- Tooth Quadrant Palmer Notation Dental Charting
- Patient Records, Appointments, Billing, Accounting & Material Stock Inventory
- Offline-first Architecture with Cloud Synchronization

## Tech Stack
- **Framework**: Next.js 15 (React 19)
- **Desktop Runtime**: Electron
- **Database**: IndexedDB (Dexie.js)
- **Styling**: Tailwind CSS, Lucide Icons

## Getting Started
```bash
npm install
npm run dev
```
